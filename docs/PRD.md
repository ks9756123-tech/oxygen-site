# 사이트 설계도(PRD) — (주)수 Water 순산소(O2) 제조기 홈페이지

작성일: 2026-10-29 · 고친 날: 2026-10-30 (사진·가격·사양·특허 반영) · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
액화산소 대신 쓰는 수조용 산소발생기를 대게·활어 유통센터, 횟집, 바다장어 어선에 공급하는 회사.
사이트의 목적: 손님이 제품을 보고 견적 문의를 남기게 해서 판매를 늘린다.

## 2. 손님
- 누가 (세 그룹 — 세 곳 모두 실제로 사용 중이고, 모두 액화산소 대신 쓰고 있음)
  1. 대게·활어 유통센터 사장님
  2. 대게·활어 횟집 사장님
  3. 바다장어 어선 (해상용) 선장님
- 어디서 알고 오나: 전단지, 업자·지인 소개
  → 현장에서 휴대폰으로 들어온다고 보고 만든다. 글자는 크게, 버튼은 크고 분명하게.

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 액화산소 대신 정말 쓸 수 있는지, 안전한지 (고압 탱크를 보관하지 않아도 되는지)
2. 비용이 얼마나 줄어드는지, 제품 가격은 얼마인지
3. 내 업장(유통센터 / 횟집 / 어선)에 맞는 제품이 무엇인지
- 설치·A/S 지역: 전국

## 6. 페이지 구성 (위에서 아래로)
**1장. 홈**
1. 첫 화면
   - 제목: 액화산소 대신 쓰는 산소발생기
   - 둘째 줄: 탱크 보관 걱정은 줄이고, 매달 드는 산소 비용은 아끼고
   - '견적 문의' 버튼 (잘 보이게)
2. 유통센터 · 횟집 · 어선 세 칸 → 누르면 각자 맞는 제품 안내로
3. 가장 큰 장점 세 가지
   - 안전: 고압 액화산소 탱크를 보관하지 않아도 됨
   - 비용 절감: 액화산소 구입 비용이 줄어듦
   - 신선도: 고농도 산소로 대게·활어가 싱싱하고 체중이 오래 유지됨
4. '액화산소 vs 산소발생기' 비교 표 (비용 숫자는 사장님이 줄 때까지 빈칸)
5. 이런 곳에서 쓰고 있어요 — 유통센터 · 횟집 · 어선 세 칸
   - 어선 칸: "바다장어 어선에서 사용 중"까지만. 선장님 후기·설치 사진은 자리만.
6. 견적 문의 폼

**2장. 제품 안내**
- 대표모델 2660A · 2660B (사진, 24시간 작동, 해수·민물 사용)
- 가격 표와 사양 표 (아래 8번)
- 특허 (가린 특허증 이미지 + 번호·명칭)
- 손님 그룹별: 유통센터용(기본) · 어선용(해상용) · 횟집용 산소분산기(해수용·내수용, 가격은 견적 문의)

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다

3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
