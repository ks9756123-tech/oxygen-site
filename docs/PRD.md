# 사이트 설계도(PRD) — 에어워트(air water) 산소발생기 홈페이지

작성일: 2026-10-29 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
액화산소 대신 쓰는 수조용 산소발생기를 대게·활어 유통센터, 횟집, 바다장어 어선에 공급하는 회사.
사이트의 목적: 손님이 제품을 보고 견적 문의를 남기게 해서 판매를 늘린다.

## 2. 손님
- 누가 (세 그룹 — 세 곳 모두 실제로 사용 중이고, 모두 액화산소 대신 쓰고 있음)
  1. 대게·활어 유통센터 사장님
  2. 대게·활어 횟집 사장님
  3. 바다장어 어선 (해상용) 선장님
- 어디서 알고 오나: (미정)
  → 현장에서 휴대폰으로 들어온다고 보고 만든다. 글자는 크게, 버튼은 크고 분명하게.

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 액화산소 대신 정말 쓸 수 있는지, 안전한지 (고압 탱크를 보관하지 않아도 되는지)
2. 비용이 얼마나 줄어드는지, 제품 가격은 얼마인지
3. 내 업장(유통센터 / 횟집 / 어선)에 맞는 제품이 무엇인지
- 설치·A/S 지역: (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 실제 사용처: 유통센터 · 횟집 · 바다장어 어선 (세 곳 모두 액화산소 대신 사용 중)
- 특허: (미정 — 번호는 사장님께 직접 받아서 넣음. 사진에서 읽지 않음)
- 설치 사진: (자리만 비워 둠)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만. 선장님 후기 포함 — 내용·숫자·배 이름은 지어내지 않음)
- 고객 수: (적지 않음)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 견적 문의
- 첫 화면에서 잘 보이게 둔다.
- 누르면: 견적 문의 폼

## 6. 페이지 구성 (위에서 아래로)
**1장. 홈**
1. 첫 화면
   - 제목: 액화산소 대신 쓰는 산소발생기
   - 둘째 줄: 탱크 보관 걱정은 줄이고, 매달 드는 산소 비용은 아끼고
   - '견적 문의' 버튼 (잘 보이게)
2. 유통센터 · 횟집 · 어선 세 칸 → 누르면 각자 맞는 제품 안내로
3. 가장 큰 장점 세 가지
   - 안전: 고압 액화산소 탱크를 보관하지 않아도 됨
   - 비용 절감: 액화산소 구입 비용이 줄어듦
   - 신선도: 고농도 산소로 대게·활어가 싱싱하고 체중이 오래 유지됨
4. '액화산소 vs 산소발생기' 비교 표 (비용 숫자는 사장님이 줄 때까지 빈칸)
5. 이런 곳에서 쓰고 있어요 — 유통센터 · 횟집 · 어선 세 칸
   - 어선 칸: "바다장어 어선에서 사용 중"까지만. 선장님 후기·설치 사진은 자리만.
6. 견적 문의 폼

**2장. 제품 안내 (손님 그룹별로 나눔)**
- 유통센터·어선용: 산소발생기 본체
- 횟집용: 산소분산기 (수조용, 해수용·내수용)
- 가격: 견적 문의 (제품마다 가격 대신 '견적 문의'로 표시)
- 각 제품마다 '견적 문의' 버튼

## 7. 문의 폼에서 받을 것
- 업체명, 연락처
- 업체 종류 (유통센터 / 횟집 / 어선 / 활어차 / 기타)
- 관심 제품 (산소발생기 본체 / 산소분산기 해수용 / 산소분산기 내수용 / 잘 모르겠음)
- 문의 내용
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 회사 이름: 에어워트(air water)
- 가격: 견적 문의
- 액화산소 대비 비용 절감: (미정 — 숫자 받을 때까지 빈칸)
- 특허번호: (미정)
- 상담 시간: (미정)
- 설치·A/S 지역: (미정)
- 전화번호: 010-9796-7989
- 연락 방법: 견적 문의 폼 / 전화 010-9796-7989

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 온라인 결제 (견적 문의로만 연결)

## 10. 첫 화면 한 문장 후보
1. 액화산소 대신 쓰는 산소발생기 (확정)
2. (둘째 줄 확정) 탱크 보관 걱정은 줄이고, 매달 드는 산소 비용은 아끼고

## 11. 다음에 할 것
- 실제 후기·설치 사진 받기 → 자리에 넣기
- 비용 절감 숫자 받기 → 비교 표 채우기
- 특허번호·서비스 지역·상담 시간 받기

## 쓰지 않을 표현
- '국내 최고', '최저가', '폭발 위험 0%', '절대 안전' 같은 단정·과장 표현

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: (미정) · 참고 디자인: 전단지·배너의 파란 바다 느낌과 물방울 로고 색만 참고, 그대로 베끼지 않음
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
